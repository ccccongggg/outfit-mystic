02

双层架构 · 一套底座，两个风格槽

工具层负责「好用」，仪式层负责「好玩」；字体/栅格/动效全共用
LAYER 01 · UTILITY

日常工具层

衣橱管理、上传入柜、搭配结果 —— 干净、留白、以内容为主。用户在这里「干活」，要的是清晰与顺手。

  • 底色 奶油白 #FAF8F5，白卡 + 极浅紫描边
  • 主行动 深紫药丸按钮，紫调柔光阴影
  • 大圆角卡片，克制的分隔线，无多余装饰
  • 信息密度偏高：单品网格 / 标签 / 元数据
☾
LAYER 02 · RITUAL

玩法仪式层

抽塔罗、生成今日氛围 —— 夜幕紫底、星光、金色细线，把「占卜」做出仪式感，情绪价值拉满。

  • 底色 夜幕紫 #211A38，星金描边 + 星点
  • 塔罗翻牌动效、星光粒子、月光手绘线
  • 宋体标题 + 斜体西文，营造神谕语调
  • CTA 用星金/浅紫渐变，与工具层的深紫形成呼应
共用 token（两层的「公约数」）

同一套间距节奏、字号阶梯、圆角与动效曲线 —— 因此两个层看起来是一家人，而不是两个 App 拼起来。

8pt 间距 同一字体家族 圆角 22 / 28px 动效曲线共用 紫调阴影语言 星金点缀 <5%
