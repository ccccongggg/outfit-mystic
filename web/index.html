拍摄规范

录入前请确认

  • 一次一件，画面只出现一件单品
  • 完整入镜，袖口 / 下摆 / 鞋头不被裁切
  • 无遮挡，手、身体、衣架、杂物不要挡住主体
  • 平铺或悬挂，尽量不穿上身（避免褶皱误判）
  • 背景干净，纯色床单 / 白墙更佳，利于抠底
  • 光线均匀，避免强阴影与过曝
  • 主体居中，约占画面 60–80%
  • JPG / PNG / WebP · 短边 ≥ 480px · ≤ 10MB
不要 多件叠放 · 模特上身特写 · 手持遮挡 · 低糊截图 · 多图拼接
