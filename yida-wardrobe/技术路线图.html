二、项目定位与现状

当前电子衣柜主方向的可运行最终综合包，可整体发给朋友演示。前端采用 wardrobe-app（原生 JS，无框架/打包/CDN，禁用 ES module，file:// 双击可跑），后端复用 outfit-mystic/server（Python 标准库 http.server，无 Web 框架）。 运行状态：http://127.0.0.1:8790/（探活 root=200，/api/v1/bootstrap 正常）。

三、技术栈

  • 前端：原生 JavaScript（Vanilla，禁用 ESM），CSS 自写，无构建器、无 CDN。
  • 后端：Python 标准库 http.server.ThreadingHTTPServer，无 Web 框架，端口 8790（原 8787）。
  • AI 流水线：rembg 抠底 → DashScope qwen-vl-max VLM 打标 → 受控词表（8 风格/24 色/7 品类）。
  • 引擎：engine.js 加权（WEIGHTS）+ Top3 + 温度/下雨降权 + 风格冲突扣分；四槽状态协议 on/skip/off/empty。
  • 数据：JSON 文件存储；web/data/offline.js 为生成物（源 data/*.json → build_offline_data.py）。

四、架构（请求流）

浏览器(wardrobe-app) → HTTP → app.py(8790)  ├─ 静态托管 / → frontend/  ├─ 适配桥 /api/v1/bootstrap、/api/v1/wardrobes/current/items（直读 frontend/data）  └─ 业务路由 /api/items、/ingest(抠底+VLM)、/api/reason(玄学文案)
